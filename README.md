# Active Citizen RPA Service

An RPA (Robotic Process Automation) service for automating participation in surveys and city update activities on ag.mos.ru.

## Technologies

* Python
* Python-Telegram-Bot
* PostgreSQL
* Celery
* Redis
* Playwright

## Implemented Features

* Automated completion of surveys and city update activities using Playwright;
* Developed a Telegram bot interface for managing and monitoring automation processes;
* Implemented generation of daily and monthly performance reports;
* Configured automated Telegram notifications with activity statistics and updates;
* Stored user and activity data in PostgreSQL;
* Utilized Celery and Redis for asynchronous task execution and scheduling;
* Built a scalable and maintainable automation workflow.
